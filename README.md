# Installation on your Phone

1. Download the petMeds.apk from this directory to your phone.
2. Run the apk on your Phone (It might prompt you with warnings but since it works offline its going to be safe).
3. Enjoy!

# Installation on PC

1. Download JetBrains [WebStorm](https://www.jetbrains.com/de-de/webstorm/)
2. Download this project as a ZIP from this GitHub Page by clicking on the "Code" Button above.
3. Unpack the ZIP File. Right click on the folder and choose "Open Folder as Webstorm Project" - This might be located
   under "More Options" on Windows 11.
4. Once opened WebStorm might prompt you to install packages, mainly npm. Click on "npm install".
5. Now you should be able to run "npm start" and click on the [localhost](http://localhost:3000/) Link to open PetMeds
   in your local Browser.
